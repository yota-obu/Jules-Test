# パスワード生成ツール

## 1. 概要

このツールは、ユーザーが指定した条件に基づいて安全なパスワードを生成するウェブアプリケーションです。クールなSF風デザインのインターフェースを採用し、視覚的にも楽しめるツールを目指しました。

## 2. 機能

ユーザーは以下の項目を設定してパスワードを生成できます。

*   **使用する文字の種類:**
    *   英語（大文字） (A-Z)
    *   英語（小文字） (a-z)
    *   数字 (0-9)
    *   記号 (!@#$%^&*()_+-=[]{}|;':",./<>?)
*   **文字数:**
    *   8文字
    *   10文字
    *   12文字
    *   その他（ユーザーが任意の長さを指定可能）
*   **指定の単語:**
    *   パスワードに含めたい任意の単語（オプション）

**主なパスワード生成の特徴:**

*   **指定単語ベース:** ユーザーが単語を指定した場合、その単語を基にパスワードを生成します。
*   **文字変換:** 指定された単語内の特定のアルファベットは、以下のように数字に変換されます。
    *   `l`, `L` → `1`
    *   `o`, `O` → `0`
    *   `s`, `S` → `5`
    *   `q`, `Q` → `9`
    *   `b`, `B` → `8`
*   **大文字・小文字ランダム変換:** 上記の文字変換後、さらに指定された単語内のアルファベットは、ランダムに大文字から小文字へ、または小文字から大文字へと変換され（例: `apple` が `aPpLe` になるなど）、予測困難性を高めます。
    生成されたパスワードは、これらの変換を経た指定単語を基に、指定された文字種と長さの条件を満たすようにランダムな文字が追加されます。指定単語の元々の文字の順序は保持され、追加文字はその間や前後にランダムに挿入されます。

## 3. 技術スタック

このアプリケーションは以下の技術を使用しています。

*   プログラミング言語: Python
*   フレームワーク: Flask
*   フロントエンド: HTML, CSS, JavaScript
*   コンテナ化: Docker

## 4. 起動方法

Docker を使用してローカル環境でアプリケーションを起動する手順は以下の通りです。

**前提条件:**

*   Docker がお使いの環境にインストールされていること。

**手順:**

1.  **リポジトリをクローン (またはコードをダウンロード):**
    ```bash
    git clone <リポジトリのURL>
    cd <リポジトリのディレクトリ>
    ```
    または、コードをZIPファイル等でダウンロードし、展開します。

2.  **Docker イメージをビルド:**
    ターミナルでリポジトリのルートディレクトリに移動し、以下のコマンドを実行します。
    ```bash
    docker build -t password-generator .
    ```

3.  **Docker コンテナを実行:**
    ビルドが完了したら、以下のコマンドを実行してコンテナを起動します。
    ```bash
    docker run -p 5000:5000 password-generator
    ```

4.  **ブラウザでアクセス:**
    ウェブブラウザを開き、アドレスバーに `http://localhost:5000` と入力してアクセスします。

## 5. 使用方法

ツールの詳細な使用方法は、アプリケーションのトップページにある「このツールの使い方 ▼」セクションで確認できます。
基本的なパスワード生成の流れは以下の通りです。

1.  **使用する文字の種類を選択:** 含めたい文字種（大文字英字、小文字英字、数字、記号）を選びます。
2.  **文字数を選択:** 希望するパスワードの長さを選びます。「その他」で任意の長さも指定可能です。
3.  **指定の単語を入力 (任意):** パスワードに含めたい単語があれば入力します。
4.  **「パスワード生成」ボタンをクリック:** 設定に基づいてパスワードが生成されます。
5.  **生成されたパスワードを確認:** 表示されたパスワードを利用します。

**入力例と出力例:**

*注意: 以下の出力例は、固定の文字変換（例: `l`→`1`）に加え、指定単語内のアルファベットに対するランダムな大文字・小文字変換、および追加文字のランダムな挿入が行われるため、実際に生成されるパスワードとは大きく異なる可能性があります。*

*   **例1:**
    *   **入力:**
        *   使用する文字の種類: 英語（大文字）, 英語（小文字）, 数字
        *   文字数: 10
        *   指定の単語: `apple`
    *   **出力例の可能性:** `aP1pLeR4n!`, `ApP1E!xYz` など。
        (固定変換で `apple` → `app1e`。その後、ランダムな大文字・小文字変換で `aPp1E` や `ApP1e` などに変化し、さらにランダムな文字が追加・挿入されます。)

*   **例2:**
    *   **入力:**
        *   使用する文字の種類: 英語（小文字）, 数字, 記号
        *   文字数: 12
        *   指定の単語: `soccer`
    *   **出力例の可能性:** `S0cCEr@!pAs`, `s0CcEr#Yz!t` など。
        (固定変換で `soccer` → `s0ccer`。その後、ランダムな大文字・小文字変換で `S0cCEr` や `s0CcEr` などに変化し、さらにランダムな文字が追加・挿入されます。)

## 6. ログ

アプリケーションの実行時には、コンソールにログが出力されます。
これらのログは、主にアプリケーションの動作状況の確認、デバッグ、および将来的な保守作業のために記録されています。
リクエストの受付、処理中の主要なステップ、エラー発生時の詳細などが記録されます。
