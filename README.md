# パスワード生成ツール

## 1. 概要

このツールは、ユーザーが指定した条件に基づいて安全なパスワードを生成するウェブアプリケーションです。

## 2. 機能

ユーザーは以下の項目を設定してパスワードを生成できます。

*   **使用する文字の種類:**
    *   英語（大文字） (A-Z)
    *   英語（小文字） (a-z)
    *   数字 (0-9)
    *   記号 (!@#$%^&*()_+-=[]{}|;':",./<>?)
*   **文字数:**
    *   8文字
    *   10文字
    *   12文字
    *   その他（ユーザーが任意の長さを指定可能）
*   **指定の単語:**
    *   パスワードに含めたい任意の単語（オプション）

**主なパスワード生成の特徴:**

*   **指定単語ベース:** ユーザーが単語を指定した場合、その単語を基にパスワードを生成します。
*   **文字変換:** 指定された単語内の特定のアルファベットは、以下のように数字に変換されます。
    *   `l`, `L` → `1`
    *   `o`, `O` → `0`
    *   `s`, `S` → `5`
    *   `q`, `Q` → `9`
    *   `b`, `B` → `8`
    生成されたパスワードは、指定された文字種と長さの条件を満たすようにランダムな文字が追加され、最終的にシャッフルされます。

## 3. 技術スタック

このアプリケーションは以下の技術を使用しています。

*   プログラミング言語: Python
*   フレームワーク: Flask
*   フロントエンド: HTML, CSS, JavaScript
*   コンテナ化: Docker

## 4. 起動方法

Docker を使用してローカル環境でアプリケーションを起動する手順は以下の通りです。

**前提条件:**

*   Docker がお使いの環境にインストールされていること。

**手順:**

1.  **リポジトリをクローン (またはコードをダウンロード):**
    ```bash
    git clone <リポジトリのURL>
    cd <リポジトリのディレクトリ>
    ```
    または、コードをZIPファイル等でダウンロードし、展開します。

2.  **Docker イメージをビルド:**
    ターミナルでリポジトリのルートディレクトリに移動し、以下のコマンドを実行します。
    ```bash
    docker build -t password-generator .
    ```

3.  **Docker コンテナを実行:**
    ビルドが完了したら、以下のコマンドを実行してコンテナを起動します。
    ```bash
    docker run -p 5000:5000 password-generator
    ```

4.  **ブラウザでアクセス:**
    ウェブブラウザを開き、アドレスバーに `http://localhost:5000` と入力してアクセスします。

## 5. 使用方法

ブラウザでツールにアクセスすると、以下の手順でパスワードを生成できます。

1.  **使用する文字の種類を選択:**
    *   「英語（大文字）」「英語（小文字）」「数字」「記号」の中から、パスワードに含めたい文字の種類を1つ以上選択します。
2.  **文字数を選択:**
    *   希望するパスワードの長さを「8」「10」「12」から選択するか、「その他」を選んで任意の数値を入力します。
3.  **指定の単語を入力 (任意):**
    *   パスワードに含めたい特定の単語がある場合は入力します。未入力でも構いません。
4.  **「パスワード生成」ボタンをクリック:**
    *   上記の設定が完了したら、このボタンをクリックします。
5.  **生成されたパスワードを確認:**
    *   ボタンの下にあるテキストエリアに、生成されたパスワードが表示されます。

**入力例と出力例:**

*注意: 以下の出力例は、ランダム性があるため、実際に生成されるパスワードとは異なります。*

*   **例1:**
    *   **入力:**
        *   使用する文字の種類: 英語（大文字）, 英語（小文字）, 数字
        *   文字数: 10
        *   指定の単語: `apple`
    *   **出力例:** `APp1E_r4Nd` (これはあくまで例です)

*   **例2:**
    *   **入力:**
        *   使用する文字の種類: 英語（小文字）, 数字, 記号
        *   文字数: 12
        *   指定の単語: `soccer`
    *   **出力例:** `s0ccEr_!p@5s` (これもあくまで例です)

## 6. ログ

アプリケーションの実行時には、コンソールにログが出力されます。
これらのログは、主にアプリケーションの動作状況の確認、デバッグ、および将来的な保守作業のために記録されています。
リクエストの受付、処理中の主要なステップ、エラー発生時の詳細などが記録されます。
