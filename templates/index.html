パスワード生成ツール

使用方法

  1. 使用する文字の種類を選択:

    「英語（大文字）」「英語（小文字）」「数字」「記号」の中から、パスワードに含めたい文字の種類を1つ以上選択します。

  2. 文字数を選択:

    希望するパスワードの長さを「8」「10」「12」から選択するか、「その他」を選んで任意の数値を入力します。（「その他」を選択した場合、隣の入力欄が有効になります）

  3. 指定の単語を入力 (任意):

    パスワードに含めたい特定の単語がある場合は入力します。未入力でも構いません。単語内の特定の文字は数字に変換され (例: l→1, o→0)、さらに一部のアルファベットは大文字・小文字がランダムに変換されることがあります。

  4. 「パスワード生成」ボタンをクリック:

    上記の設定が完了したら、このボタンをクリックします。

  5. 生成されたパスワードを確認:

    ボタンの下にあるテキストエリアに、生成されたパスワードが表示されます。

入力例と出力例

注意: 以下の出力例は、ランダム性があるため、実際に生成されるパスワードとは異なります。特に、指定単語内のランダムな大文字・小文字変換や、追加文字の挿入位置によって結果は多様になります。

例1:

  • 入力:
    • 使用する文字の種類: 英語（大文字）, 英語（小文字）, 数字
    • 文字数: 10
    • 指定の単語: `apple`
  • 出力例の可能性: `APp1E_r4Nd` (変換後 `app1e` の `a` が `A` に、`p` が `P` にランダム変換され、`_`,`r`,`4`,`N`,`d` がランダムに追加・挿入された場合。実際の出力はこれとは異なります)

例2:

  • 入力:
    • 使用する文字の種類: 英語（小文字）, 数字, 記号
    • 文字数: 12
    • 指定の単語: `soccer`
  • 出力例の可能性: `s0c#CER@t5!` (変換後 `s0ccer` の `c` が `C` に、`e` が `E` に、`r` が `R` にランダム変換され、`#`,`@`,`t`,`5`,`!` がランダムに追加・挿入された場合。実際の出力はこれとは異なります)

指定単語の文字の順序は保持され、追加文字はその間や前後にランダムに挿入されます。
